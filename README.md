# Maxus Builder — Real Estate & Heritage Property CRM

Official Sales, Site Visit Photo Log, and Joint Venture CRM for **Maxus Builder** (18-19, Lav Kush Marg, Shyam Nagar, Jaipur | +91 98281 99333 | https://www.maxusbuilder.com/).

## Quick Push to GitHub & Host on Vercel

1. Unzip this folder and open a terminal inside `maxus-builder-crm`:
   ```bash
   git add .
   git remote add origin https://github.com/<your-username>/maxus-builder-crm.git
   git push -u origin main
   ```
2. Go to [https://vercel.com/new](https://vercel.com/new) and import your `maxus-builder-crm` GitHub repository, or run:
   ```bash
   npx vercel --prod
   ```
